# זירה – משחקי מסיבה (מסך גדול + טלפונים כשלטים)

שמונה משחקים: **מרוץ** (הטיה + טורבו), **אגרוף**, **הוקי אוויר**, **כדורגל ראשים**, **טנקים**, **אופנועי אור**, **סומו**, **דו־קרב**, ומצב **טורניר** של 5 משחקים אקראיים.
שחקן שהטלפון שלו ננעל או התנתק חוזר אוטומטית לאותו מקום (עד 30 שניות).
המסך הגדול (טלוויזיה/מחשב) מריץ את המשחק, עד 2 טלפונים מתחברים עם קוד חדר או סריקת QR.
שחקן לבד? המחשב משחק נגדו אוטומטית.

## העלאה לאוויר בחינם (Render) – בערך 10 דקות
1. פתחו חשבון ב-GitHub וצרו Repository חדש בשם `zira`.
2. העלו לתוכו את כל הקבצים מהתיקייה (Add file → Upload files), **חוץ מתיקיית `node_modules`**.
3. היכנסו ל-render.com, התחברו עם GitHub ובחרו **New → Web Service** ואת ה-Repository.
4. הגדרות: Build Command: `npm install` · Start Command: `npm start` · Instance Type: **Free**.
5. לחצו Create. תקבלו כתובת כמו `https://zira-xxxx.onrender.com`.

* המסך הגדול: פותחים את הכתובת בדפדפן של הטלוויזיה/המחשב.
* הטלפונים: סורקים את ה-QR שעל המסך (או נכנסים ל-`/play` ומקלידים את הקוד).
* בחינם השרת "נרדם" אחרי 15 דקות בלי שימוש – הכניסה הראשונה לוקחת עד דקה.

## הרצה על המחשב (לבדיקות)
```
npm install
npm start
```
ואז http://localhost:3000. שימו לב: חיישן ההטיה בטלפון עובד רק בכתובת https (כמו ב-Render). ברשת הביתית בלי https השלט עובר אוטומטית לכפתורי חצים.

## טיפים
* מרוץ: אם ההגה הפוך – כפתור "⇄ הפוך". "כיול" מאפס את מצב הישר.
* אגרוף: מכה בזמן שהיריב מתכונן = קאונטר (×1.5). מכות שנוחתות ממלאות את ה"סופר".
* מקלדת במסך: Esc חוזר לתפריט.

## מבנה
* `server.js` – שרת חדרים (Express + Socket.IO) ו-QR.
* `public/index.html`, `public/screen.js` – המסך הגדול וכל המשחקים.
* `public/play.html`, `public/play.js` – השלט בטלפון.
